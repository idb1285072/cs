# DataType

## What?

- **Type** specifies what type of value to be store in memory
- Type is a.k.a. Data Type

## Primitive Types and Non-Primitive Types

- **Primitive Type**
  - primitive type store **single value**
  - primitive type are **basic building blocks** of non-primitive types
  - Example: `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `float`, `double`, `decimal`, `char`, `bool`
  - `sbyte.MinValue`, `sbyte.MaxValue`, `default(sbyte)`
- **Non-Primitive Type**
  - Store one or more values
  - usually contains multiple members
  - Example: `string`, Class, Interface, Structure, Enumeration
