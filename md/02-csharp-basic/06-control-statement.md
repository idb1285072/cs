# Control Statement

## What?

- Control Statement are used to control the program execution flow
- Used to make the execution flow "jump forward" or "jump backward"

## Classification

- Conditional Control Statement
  - if(simple-if, if-else, else-if, nested if)
  - switch-case
- Looping Control Statement
  - while
  - do-while
  - for
- Jumping Control Statement
  - goto
  - break
  - continue
