# Conditional Control Statement

- Simple if
  ```cs
  if (condition)
  {
    // true block
  }
  ```
  Examples
  ```cs
  if (x<10)
  {
    System.Console.WriteLine("x is smaller than 10");
  }
  ```
- if-else
  ```cs
  if (condition)
  {
    true block
  }
  else
  {
    false block
  }
  ```
  Examples
  ```cs
  if (x > 10)
  {
    System.Console.WriteLine("x is larger than 10");
  }
  else
  {
    System.Console.WriteLine("x is smaller than or equal to 10");
  }
  ```
- else-if
  ```cs
  if (condition1)
  {
    true block 1
  }
  else if (condition2)
  {
    true block 2
  }
  else
  {
    false block
  }
  ```
  Examples
  ```cs
  if (x > 10)
  {
    System.Console.WriteLine("x is larger than 10");
  }
  else if (x < 10)
  {
    System.Console.WriteLine("x is smaller than 10");
  }
  else
  {
    System.Console.WriteLine("x is equal to 10");
  }
  ```
