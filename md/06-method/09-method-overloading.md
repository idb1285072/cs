# Method Overloading

## What?

- multiple methods with **same name** in the **same class**, with **different parameters**

## Why?

- Improves readability
- Provides flexibility
- Reduces unnecessary method names

## Example

```cs
MethodName()
MethodName(int)
MethodName(string)
MethodName(int, int)
MethodName(string, string)
MethodName(int, string)
MethodName(int, int, int)
```
