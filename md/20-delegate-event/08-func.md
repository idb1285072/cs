## What?

- `Func` is a pre-defined generic delegate, which can be used to create quickly
- `Func` supports parameters and return value also.
  - `Func` must have 0 to 16 parameters
  - `Func` must have return value

## How?

```cs
public Func<Param1DataType, Param2DataType, ..., ReturnType> referenceVariables;
```
