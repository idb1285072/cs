- Object is a programmatic representation of person or thing.
- All objects are created based on classes, store in heap
- For each application execution, a new heap will be created (and only one)
- All reference variables (local variables of methods) are stored in stack. For each method call, a new stack will be created
- Method is collection of statements to perform some operation/ calculation
- Class supports two access modifiers: `internal`, `public`
- Class supports four modifiers: `static`, `abstract`, `sealed`, `partial`
- Object stores actual data (group of fields) & can access methods of class
- A reference variable stores address of an (only one) object

> Single Value - Field
> Operation/Calculation - Method
