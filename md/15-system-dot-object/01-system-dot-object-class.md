# `System.Object` class

## What?

- The `System.Object` is a pre-defined class, which is the **Ultimate super class (base class)** in .net
- All the classes and other types are inherited from `System.Object` directly / indirectly

## 🧩

```cs
System.Object
  - System.ValueType
    - Structures
    - Enumerations
  - Classes
  - Interfaces
```
