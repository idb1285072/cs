# .NET Framework vs .NET Core vs .NET

|             | **.NET Framework** | **.NET Core**   | **.NET**        |
| ----------- | ------------------ | --------------- | --------------- |
| Introduced  | 2002               | 2016            | 2020            |
| Platform    | **Windows only**   | Cross-platform  | Cross-platform  |
| Status      | Legacy             | Renamed/evolved | **Current**     |
| Open source | Partly             | Yes             | Yes             |
| Performance | Older              | Better          | **Best/modern** |
| Use today   | Existing old apps  | Old Core apps   | **New apps**    |

## Simple history

**.NET Framework → .NET Core → .NET**

- **.NET Framework** = original Windows-focused platform. (version 1.0 to 4.8.1)
- **.NET Core** = Microsoft's redesigned, cross-platform version. (version 1.0 to 3.1)
- **.NET** = the unified successor to .NET Core, starting with **.NET 5**. (version 5.0 and so on)

So:

> **.NET Core is not a separate modern platform anymore. It evolved into simply “.NET.”**
